# Smart Personal Expense & Budget Tracker

A Python-based desktop application that helps users manage their daily expenses, set a monthly budget, analyze spending patterns, search expenses, and export expense records.

## Problem Statement

Managing daily expenses manually can make it difficult to track spending, monitor a monthly budget, and understand where money is being spent.

## Solution

The Smart Personal Expense & Budget Tracker provides a simple graphical interface where users can:

- Add daily expenses
- View expense records
- Edit existing expenses
- Delete expenses
- Search expenses
- Set a monthly budget
- View budget summary
- Analyze expenses by category
- Visualize spending using graphs
- Export expense records to CSV

## Technologies Used

- Python
- Tkinter
- SQLite
- Matplotlib
- CSV

## Main Features

### Expense Management
Users can add, view, edit, delete, and search their expense records.

### Budget Management
Users can set a monthly budget and monitor their total spending and remaining budget.

### Expense Analysis
The application analyzes expenses based on categories and displays the results using a graph.

### CSV Export
Users can export their expense records into a CSV file for further use.
